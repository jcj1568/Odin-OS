Quick Reference — Colors & Type

Color

Navy #142544 — primary background
Gold #E3B23C — accent only, never body text at small size
Frost #ECEEF2 — text on navy
Ink #14171B — text on gold or paper

Usage rules

  • Hagalaz-H wordmark is now the one consistent lockup — used everywhere, no separate "plain" version
  • Icon mark needs min. 24px clearspace on all sides equal to the icon's own width
  • Gold never used for body copy — accent and single-line taglines only
Beyond what's here, three things worth doing before this goes out into the world: (1) finish the USPTO trademark search on "Hymdal" in software/AI classes that we flagged earlier and never closed the loop on — collateral is cheap to redo now, expensive to redo after it's on client-facing material; (2) check the navy/gold and gold/black color pairs against WCAG contrast minimums if any of this ends up in a web UI, not just print/static images; (3) view the 16px favicon on an actual browser tab, not just in this mockup, since screen rendering can differ slightly from this preview.
